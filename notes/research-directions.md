# Directions for further experiments

The following are development and investigation tasks, not claims of open
problems in the literature.

1. **Compare exponents.** Tabulate solution dimensions as $n$ varies. Powers
   on a finite group repeat, so investigate periodicity using orders of units.
2. **Commuting solutions.** Add the linear constraints
   $[f(X),X]=0$ for every matrix $X$ and compare the resulting kernel with
   the inverse-identity solution space.
3. **Triangular and incidence algebras.** Replace the matrix basis and
   multiplication table with those of a finite-dimensional algebra, then
   enumerate its units. Keep the ambient algebra explicit in all results.
4. **Matrix substitutions.** Build exact examples using matrix units to
   test proposed additivity identities for matrix polynomials.
5. **Proof development.** Use small examples to identify necessary
   hypotheses, then seek symbolic arguments via linearization, Hua-type
   identities, or commuting-map reductions. Record all invertibility
   assumptions before using an inverse.

Before describing any resulting question as open or any result as novel,
perform a separate literature review. Finite experiments cannot certify
novelty or establish general division-ring results.
